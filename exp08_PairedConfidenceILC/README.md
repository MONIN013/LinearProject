# Exp08: 同一FFペアによる信頼度付きILC

`paired_confidence_experiment.m` が入口。exp04と同じ軌道・FB・有限長Q・取得処理を使い、
全手法を30回学習、最後に得たFFを5回固定して比較する。

比較するのは通常ILC、未補正履歴ゲート、同一FFペア平均、ペア信頼度付き平均の4手法。
ペア法は奇数回の後にFFを保持し、偶数回の2計測から次候補を作る。30回目から作った候補は
学習中には未印加で、固定評価の1回目が初回適用となる。

ペアの候補更新量を `d1, d2` とし、`S=max(d1'*d2,0)`、`V=norm((d1-d2)/2)^2`、
`w=S/(S+V)`（分母0なら0）で更新全体を緩和する。2候補の学習率は偶数回終了時の値に揃える。
入力に掛ける重みは記録全体のスカラー1個。位置・方向別の重みはCSVに診断用として残す。

第4節は実機を動かす。各学習・固定評価の前に54,100,000 countへHomingし、前後の無励磁、
欠落、追従、2 A上限を共通取得処理で確認する。結果は `data/ilc/<日時_exp08_paired_confidence>/`
へ保存する。手法順はseed 8で記録する。1ブロックの結果は記述比較であり、手法差を判断する場合は
別の順序seedでも完全なブロックを取得する。

更新式を変更した場合の最小確認は `check_exp08`。有限長Qを含むペア更新とFF保持を確認する。

2026-09-22: MATLAB R2025aで更新式の確認と実機140走行を完了した。
全走行で欠測・fault・飽和なし。同一ペアのFF一致と固定評価中のFF不変も照合済み。
固定評価の全区間平均RMSは、ペア信頼度4.77 µm、ペア平均5.41 µm、通常6.34 µm、
未補正履歴ゲート8.07 µm。詳細は [実機確認結果](../docs/ilc-repeatability-verification-2026-09-22.md) を参照。

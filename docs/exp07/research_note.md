# ILC 教師信号の反復再現性と学習過渡の補正

固定子間欠配置PMLSMの卒論手法を発展させる Exp07

2026-09-21 / 数値検証と実験計画 / **実機・MATLAB未検証**

## 要旨

卒論では、ILCで得た補償電流を複数速度から成分分離し、位置・速度に依存するFFへ変換していた。Exp07はその教師取得段階を対象とする。従来の更新量をそのまま反復平均・分散へ入れると、雑音のない収束過渡まで「ばらつき」として数える。そこで、既知の公称閉ループモデルで過去の誤差を同じ入力条件へ換算してから平均する。さらに、Qフィルタ全体の更新を緩和するスカラーゲートの追加効果を比較する。

合成された閉ループ誤差空間の数値例では、独立雑音条件の固定FFによる反復可能誤差RMSが 0.857 µm から 0.574 µm に減少した。ただし観測誤差RMSは 2.177 µm から 2.079 µm への変化である。ドリフト条件では逆に 3.267 µm から 7.027 µm へ悪化した。したがって「反復変動を全般に抑える新手法」とは結論しない。定常的な反復雑音に対する教師信号取得法の候補として、既存実験系で検証する。

## 1. 卒論から何を残し、何を変えるか

既存の `exp04_ILC` は位置誤差 e から学習フィルタ L で補償電流の修正量を作り、Qを通して次のFFを生成する。卒論の成分分離モデルは次式である。

$$I(x,v)\simeq a(x)v+b(x)+d(x)\operatorname{sign}(v).$$

この回帰には同じ位置で独立な速度条件が必要である。一往復の反復だけでは、局所の2観測に対して3未知係数となる。未知位置関数を任意に許す場合、反復数を増やしても識別不能性は解消しない。加速度係数を追加すれば必要な独立条件はさらに増える。これは複数速度を用いた卒論の否定ではなく、単一学習軌道による一般化案の条件整理である。

Exp07は位置基底、FFの空間写像、電流配分を変更しない。教師FFの試行間変動を減らすことを狙い、同一軌道での再現性を測定する。ILCのFFには軌道追従、駆動系の遅れ補償、外乱補償が重畳しうるため、FFそのものを物理的な外乱力と同一視しない。

[1]〜[5]の公開一次資料の抄録・書誌情報を中心に確認した。原著全式を再現した網羅的比較ではなく、直接同値な先行更新則が存在しないことを確認したわけでもない。

近接する2026年の研究として、Tsurumoto・OhnishiのPMSMにおけるセンサレス脈動分解とFF補償も公表されている [6]。書誌と著者による説明を確認した段階であり、本PRとの更新則の同値性は未確認である。ILCを教師データ取得に用いること自体も、新規性として切り出さない。

**新規性の判定:** 公称モデルによる外乱再構成、反復平均、緩和更新はいずれも既知の設計要素と重なる。「世界初のRCS」や「新しいILCの一般理論」は主張しない。今回の検証仮説は、(i)学習過渡を除いた統計が未補正統計より妥当か、(ii)Qの固定点を変えないゲートに平均化以上の効果があるか、(iii)その効果が当該教師取得工程の再走行性能に現れるか、である。独立した学術的新規性の成立は、近接研究との数式レベルの比較と実機結果の後に判断する。

## 3. 信号の定義と既存ILC

同じ参照軌道・初期化条件で、有限長ベクトルとして

$$e_k=b-Jf_k+n_k,\qquad J=\frac{P}{1+PC}$$

と置く。fは既に印加したFF電流指令、eはエンコーダから得る位置誤差、bは反復可能な参照・外乱の寄与、nは反復変動成分である。PMLSM全体が厳密にLTIであるとの主張ではなく、公称軌道周辺でのモデル仮定である。

既存の実装は

$$L\simeq\widehat J^{-1}=C+P_n^{-1},\quad
\alpha_k=\max(0.9^k,0.3),\quad
f_{k+1}=\mathcal Q(f_k+\alpha_kLe_k).$$

ここで $\mathcal Q$ は `filtfilt_clean` と25 msの端処理を含む実際の有限長演算を表す。因果的な Q(z) を二回適用する演算ではない。既存の4次Butterworth、420 Hz、既存の電流上限は維持する。Lへ入力するのは位置誤差であり、観測していない電流誤差ではない。

Qが恒等でない場合、誤差の収束先は一般にゼロではない。固定alphaの公称反復では

$$f_*=\mathcal Q[(I-\alpha LJ)f_*+\alpha Lb]$$

を満たす点へ収束する。以下の固定点保存は、この点を保存するという意味である。

## 4. 収束過渡を取り除いてから平均する

$B=L\widehat J$ として、各試行から

$$z_k=Le_k+Bf_k$$

を作る。誤差式を代入すると

$$z_k=Lb+L(\widehat J-J)f_k+Ln_k.$$

モデルが一致すれば f の学習過渡は消える。単純な `f+Le` は $L\widehat J=I$ の特殊な場合なので、有限長の逆モデルでは Bf を明示的に計算する。

直近m試行のzを平均し、現在のFFへ換算した修正量を

$$\overline\delta_k=\overline z_k-Bf_k$$

とする。その候補は

$$F_k=\mathcal Q(f_k+\alpha_k\overline\delta_k)
=\mathcal Q(f_k-\alpha_kBf_k)+\alpha_k\overline{\mathcal Qz}_k.$$

この形なら過去の `Qz` を保存すればよい。`transport_mean` は $f_{k+1}=F_k$ とする。モデル一致・雑音ゼロ・同一bなら全てのzが一致するので、窓長によらず既存ILCと同じ更新になる。

**成立範囲:** モデル不一致では $L(\widehat J-J)f_k$ が残り、学習過渡を完全には除けない。位置依存の推力変動、非線形摩擦、異なる初期状態、温度変化も誤差源となる。「位置と電流指令だけで真の外乱を一意に識別した」とは解釈しない。

## 5. ゲートはQの外側で更新全体に掛ける

$\overline d_k=F_k-f_k$ とする。独立・定常な試行雑音の下で平均の雑音エネルギーを近似する量として

$$V_k=\frac{\alpha_k^2}{m}\sum_t
\widehat{\operatorname{Var}}_j[(\mathcal Qz_j)(t)]$$

を用い、比較用のスカラーゲートを

$$g_k=\max\left(0.1,\frac{\|\overline d_k\|_2^2}
{\|\overline d_k\|_2^2+V_k}\right),\qquad
f_{k+1}=f_k+g_k(F_k-f_k)$$

と定義する。m<2または分母ゼロならg=1。これはプラグイン型のヒューリスティックであり、最小MSEや最適性の証明ではない。閉ループ履歴との相関、相関雑音、モデル誤差、ドリフトにより解釈は変わる。全記録を一つのスカラーで抑制するため、局所的な雑音にも全体の学習が遅くなるという欠点もある。

### 固定点と条件付き収束

雑音がなく、モデルが一致し、alphaが固定された場合、通常ILCを $F(f)=Af+c$ と書く。$A=\mathcal Q(I-\alpha LJ)$ に対して、共通の誘導ノルムで $\|A\|\le\rho<1$ なら

$$\|f_{k+1}-f_*\|\le[1-g_k(1-\rho)]\|f_k-f_*\|.$$

したがって $0.1\le g_k\le1$ のスカラー緩和は、この条件下で固定点と収束性を保つ。一般の時刻別ゲート、雑音下の確率収束、モデル不一致下で履歴平均を含む系、非線形実機への証明ではない。実装のalphaは最終的に0.3へ固定される。周波数応答の大きさの確認だけで、端処理を含む有限長演算の共通ノルム条件を証明したとは扱わない。

一方、$f_{k+1}=\mathcal Q(f_k+\alpha g_kLe_k)$ は別の更新であり、g=0でも記憶が変わる。例としてQ=0.8、LJ=1、Lb=1、alpha=0.3の通常ILCの固定点は0.54545である。g=0.2をQの内側へ置くと、そこから一回で0.45818へ移り、固定点を保たない。全体緩和なら0.54545のままである。

## 6. 比較法と再現可能な合成数値例

比較は `standard`、`raw_rcs`、`transport_mean`、`transport_rcs` の4法。`raw_rcs` は過去の未補正更新量の平均・分散から同型のゲートを作り、現在の通常ILCの更新を緩和する診断用アブレーションである。特定の原著の追試とは呼ばない。

数値例はPythonで実行した閉ループ誤差空間のモデルであり、実機ログやMATLABの出力ではない。合成JはPDで安定化された質量・粘性モデルに遅れを付加した周波数応答を用いる。全記録を円環として扱い、Lは正則化周波数逆である。**実機の有限長安定逆・端処理と同一ではない。** 任意の軌道の機械・電気動作を検証するシミュレータでもない。

| 項目 | 設定 |
|---|---|
| 標本化・記録 | 4 kHz、4096点 |
| 合成モデル | M=0.6 kg、D=3 N s/m、Kt=20 N/A、Kp=2000 A/m、Kv=14 A s/m、遅れ2標本 |
| 学習・評価 | 15回印加、最後に印加したFFを5回固定再生 |
| 反復統計 | 窓長5、最小ゲート0.1、alphaは既存と同じ |
| Monte Carlo | 各条件32シード、全手法で同じ雑音実現値 |
| 独立雑音 | 位置誤差へ帯域制限雑音、設計RMS 2 µm、帯域形状 exp[-(f/180)^4] |
| モデル不一致 | 真値のMを0.75 kg、遅れを3標本へ変更 |
| ドリフト | 要求補償波形へ最大0.04 Aの正弦形状を試行1〜15で線形増加 |
| 相関雑音 | 反復方向AR係数0.8、初期値ゼロ、replayまで同じ過程を継続 |

「学習過渡の補正」と「本当に変化する外乱の追跡」を区別するため、ドリフトを不利な条件として残した。設定は `simulate_reference.py` と `synthetic/settings.json`、全結果の平均表は `synthetic/summary.csv`、代数確認は `synthetic/checks.json` に記録する。スクリプトを実行するとseed別CSVと図も生成する。

### 固定FFの反復可能誤差RMS [µm]

シミュレーションでのみ真値が分かる $b-Jf$ のRMS。各条件32シードの平均であり、実機の位置精度ではない。

| 条件 | 通常ILC | 未補正ゲート | 過渡補正平均 | 過渡補正平均＋ゲート |
|---|---:|---:|---:|---:|
| 雑音なし・モデル一致 | 0.000260 | 0.008469 | 0.000260 | 0.000260 |
| 独立雑音 | 0.857 | 0.606 | 0.683 | 0.574 |
| モデル不一致＋独立雑音 | 0.837 | 0.610 | 0.676 | 0.595 |
| ドリフト＋独立雑音 | 3.267 | 5.415 | 5.213 | 7.027 |
| 相関雑音 | 1.630 | 1.527 | 1.533 | 1.455 |

雑音なしでは補正平均のFFと通常ILCのFFの最大差は $3.61\times10^{-16}$ Aだった。未補正ゲートは雑音ゼロでも平均0.816へ低下した。この極小誤差の数値を、0.1 µm級の位置検出を備えた実機で達成できるという予測には用いない。

独立雑音の条件では、平均化にゲートを追加した差は -0.110 µm、同じ32シードの対応差から計算した近似95%区間は [-0.115, -0.104] µmだった。これは指定したモデル・雑音分布についてのMonte Carlo誤差であり、未知の実機や温度・速度条件への信頼区間ではない。

観測誤差RMSには新しい雑音が含まれる。独立雑音条件の通常ILCと補正平均＋ゲートは、それぞれ2.177 µmと2.079 µmであり、反復可能誤差で得た約33%という改善率を観測誤差に適用できない。相関雑音ではreplayも学習と相関しており、観測誤差の順位と反復可能誤差の順位は一致しなかった。この結果を独立検証データの性能として扱わない。

**負の結果:** ドリフトでは全ての平均化・ゲート法が通常ILCに劣る。補正するのは入力fが変わった影響であり、b自体の変化ではない。平均化の遅れとゲートが追従を妨げる。Exp07では自動ドリフト判定や切替機構を付け足さず、適用条件を実験で判断する。

## 7. 実機で何を示せば研究上の結論になるか

`repeatability_experiment.m` はexp04の設定、プラント、FB、L、Q、取得・保存・停止処理を共用する。単一FFの注入点は変えず、Simulink / PLC / MotorRuntimeは変更しない。各手法を同一軌道・同一15試行で学習し、最後に実際に使用したFFを固定して再走行する。実機に外乱を人工注入する機能は追加していない。

学習中のRMSだけで比較せず、固定FF再走行の位置誤差RMS、試行平均誤差波形、試行間標準偏差、最大誤差、最大電流指令を記録する。同一の試行数・軌道・制御器で比較し、手法順をブロックごとに変更して温度ドリフトを調べる。学習を止めた状態でも良い性能が再現するかを主評価とする。

この段階で示せるのは教師取得の再現性であり、a(x),b(x),d(x)の真値の回復や別軌道の精度ではない。卒論の成分分離へ進む場合は、独立な速度条件で取得した教師を同じ回帰処理へ渡し、別の速度条件を残して評価する。この一般化実験は本PRには含めない。

## 8. 実装と残る確認

変更する共通ファイルは `exp04_ILC/obtainMeasurement.m` 一つ。単一軌道の初期FFと反復更新callbackを任意指定にし、未指定時の既存更新式・取得処理を保持する。速度スイープは同じ呼出し経路を維持する。既存の入力上限、欠落確認、25 ms端処理、停止・切断・生データ退避を残す。新しい安全システムやテスト基盤は作らない。

本環境ではMATLAB / Octaveがなく、`check_exp07.m`、実機スクリプト、TwinCATは未実行。Pythonの代数・合成例の検証は実施済み。追加した確認関数は一つだけであり、実機操作を行わない。MATLAB上の演算一致と実機の再走行結果が得られるまでは、実装を実機検証済みとは扱わない。

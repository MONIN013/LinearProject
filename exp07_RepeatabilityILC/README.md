# Exp07: ILCの反復再現性

入口は `repeatability_experiment.m`。`exp04_ILC/ilc_experiment_neo.m` と同じ設定・
プラント・FB・Q420 Hzを使い、位置誤差からのFF更新方法を比較する。

| 手法 | 更新方法 |
|---|---|
| `standard` | exp04の更新をそのまま適用 |
| `raw_rcs` | 未補正の過去更新量のばらつきで更新を緩和 |
| `transport_mean` | `L*e + L*Jhat*f` の5試行平均から現在のFFの更新を計算 |
| `transport_rcs` | 同じ平均に、ばらつきによる更新の緩和を追加 |

共通条件は原点54,100,000 count、往路1.25 m、速度0.3 m/s、`a_max=12`
（生成器への引数は6、軌道のピーク加速度は9 m/s²）。前後待機1.5秒、折返し待機1秒。
4手法の順番を `orderSeed=7` で決め、各15回学習した後、最後に実際に適用したFFで
同じ軌道を5回再走行する。平均窓は5、最小更新ゲートは0.1。

リポジトリルートで `setup_project` を実行して入口を開き、節を順に実行する。
第5節で実機が動く。各学習・再走行の前に既存の `home_to_start` で原点へ戻し、
前後の停止・無励磁と帰着位置を確認する。計測・電流上限・通信異常時の停止は
`exp04_ILC/obtainMeasurement.m` を共用する。モデル・周期・固定バッファが変わらなければ
再ビルドは不要。`teacherSettings` と `ilcExtension` は併用しない。

結果は `data/ilc/<日時_exp07_repeatability>/` に保存する。
`block.mat` は条件と各 `training.mat` / `replay.mat` への参照を持つ。
各結果MATに履歴・生計測・Homing・前後状態をまとめ、履歴をblockへ重複保存しない。
中断時は各実行ディレクトリの `ilc_progress_single.mat` とrawに途中結果が残る。
第6節は学習曲線、再走行RMS、平均誤差、試行間のばらつき、飽和点数を保存する。
固定再走行の飽和点数が0で、FFが変わっていないことを比較の完了条件とする。

これは1つの順序での記述統計であり、温度・時間変化を除いた手法の優位性は判定しない。
更新関数を変更した場合の最小確認は、本フォルダをpathへ追加して `check_exp07` を1回実行する。

2026-09-22: 80走行と保存結果の照合を完了した。全走行で欠測・fault・飽和なし。
固定評価の平均RMSは通常10.38 µm、過渡補正平均9.15 µm、同平均＋ゲート7.12 µm、
未補正履歴ゲート5.24 µm。詳細は [実機確認結果](../docs/ilc-repeatability-verification-2026-09-22.md) を参照。

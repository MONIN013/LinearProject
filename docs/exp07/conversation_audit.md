## 修正すべき論点

### 1. 一往復だけでは局所の任意係数を同定できない

固定された絶対位置 x を往路・復路で一度ずつ通る場合、局所設計行列 `[v,1,sign(v)]` は2行3列で rank <= 2。同じ軌道の反復は雑音を減らすが行の独立性を増やさない。同じ絶対速度 V で往復する例では、`a -> a+lambda`, `d -> d-V*lambda` が学習データを変えない。したがって任意に未知な a,d の別速度への転用を保証できない。

回転角を複数回通過する実験なら、角度に対して外乱が周期的であるという仮定の下で異なる速度での観測を増やせる。しかし、リニアモータの固定子端・組立誤差を、電気角に剰余を取るだけで周期化してよいわけではない。基底の低次元性・平滑性・物理的共有構造を仮定すれば推定可能性は変わるが、それは追加の仮定である。

この指摘は**複数速度で教師データを取った卒論**を否定するものではない。「学習軌道を一つに減らして任意速度へ転用する」という発展案の制約を示す。

### 2. L は電流誤差ではなく位置誤差へ作用させる

`e=r-y`, `J=P/(1+PC)` とし、既存の `L ~= Jhat^-1 = C+Pn^-1` を維持する。真の外乱電流や実電流を観測済みとして更新する比較は成立しない。Exp07 は `history.e` と既に印加した FF のみを更新に使う。

### 3. 空間メモリと空間領域の動的ILCを区別する

時間領域で Le を計算して位置・方向へ写像する方法は、位置同期メモリを持つ更新として記述できる。座標を変更しただけで制御対象の速度依存性や識別条件が消えるわけではない。SHGI 等の完全な定義は未取得の共有本文に依存しうるため、見えている略称だけから再実装しない。

### 4. 収束トレンドと反復雑音を分ける

雑音ゼロでも更新量が `delta_k=rho^(k-1)*delta_1` と減衰すれば窓内分散は正になる。その分散から学習率を下げると、正常な学習過渡まで抑制する。この会話上の疑問を、Exp07 の検証可能な主題にした。

### 5. Q とゲートの配置、収束後誤差を混同しない

`f_next=Q(f+alpha*g*Le)` では g=0 でも `Qf` へ変わる。`f_next=f+g*(Q(f+alpha*Le)-f)` と区別する。Qが恒等でなければ、安定に収束しても追従誤差ゼロとは限らない。`filtfilt` の実効周波数応答は原則として前向き・後向きの積であり、因果フィルタを二回通す伝達関数そのものではない。

## Exp07 の位置づけ

対象を「同一軌道での教師FFの再現性」に絞る。学習1軌道・評価5軌道の一般化試験は今回実装していない。5回の固定FF再走行は、その代用品ではない。卒論の成分分離へ展開するときは、必要な独立速度条件で教師取得を繰り返す。
